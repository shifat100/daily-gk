# Written in action script 3.0
### How to Compile

#### Via Adobe Animate / Flash Pro
1. Create a new **ActionScript 3.0** document.
2. In Properties:
   - Width: `320`, Height: `480`
   - Background Color: `#12161E`
   - Frame rate: `30`
   - Document class: `DailyGK`
3. Save the `.fla` in the same directory as `DailyGK.as`.
4. Press **Ctrl + Enter** (or **Cmd + Enter**) to compile and launch.
