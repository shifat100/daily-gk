# Daily GK for Acode

Play and study pre-rendered `.PAK` MCQs directly inside the Acode editor on Android.

## Features
- **Binary DGK1 Engine**: Direct 1-bit monochome bitmap rendering on HTML5 canvas.
- **IndexedDB Package Storage**: Offline storage for your `.PAK` collections.
- **Study & Quiz Modes**: Toggle between instant-answer Study Mode and test-scoring Quiz Mode.
- **Full Navigation**: Jump to questions, search by keyword with full UTF-8 support.
- **Hardware Back Support**: Fully integrated with Acode's native back action stack.
- **Mobile Optimized**: Clean touch targets and retro softkey bar layout.

## How to Use
1. Open the Command Palette (`Ctrl+Shift+P`) and choose **Daily GK: Open Quiz Player** (or tap the sidebar icon).
2. Tap **+ Import .PAK** and select your `.PAK` files.
3. Tap any package to begin practicing.
